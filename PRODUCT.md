# PRODUCT.md — GCP Forge (Google Cloud Developer Academy)

## Vision & Purpose
GCP Forge is a premium, interactive, roadmap-first learning ecosystem designed to take developers from absolute cloud zero to production-grade Google Cloud Platform engineering and architecture. Unlike static documentation sites or traditional course dashboards, GCP Forge uses an interactive visual roadmap (inspired by roadmap.sh, tailored for Google Cloud) as the primary learning canvas.

Every node maps to real, production-tested, current GCP learning modules, featuring dual execution modes (Google Cloud Console + gcloud CLI + Terraform), interactive architectural diagrams, step-by-step practical labs with explicit cost warnings and cleanup steps, interview preparation matrices, and searchable command libraries.

## Target Audience
- Software engineers transitioning to Google Cloud Platform.
- DevOps & platform engineers building CI/CD, IaC, and Kubernetes clusters.
- Solutions architects designing high-availability, multi-tier, zero-trust cloud applications.
- Cloud beginners seeking an authentic, technically rigorous, step-by-step engineering pathway.

## Core Pillars
1. **Roadmap-First Experience**: Visual, connected learning paths with stages, prerequisites, branch filtering, zoom/pan navigation, and persistent progress.
2. **Dual-Method Learning**: Every operational guide provides both Console walkthroughs and copyable, annotated `gcloud` CLI commands, supplemented with declarative Terraform snippets.
3. **Architectural Clarity**: Visual system diagrams illustrating real traffic flow, security boundaries, and protocol handoffs (e.g. Browser -> Cloud Armor / HTTPS LB -> Serverless NEG -> Cloud Run -> Private Service Access -> Cloud SQL).
4. **Safety & Cost Transparency**: Clear distinction between free-tier eligible operations and paid services, with prominent cost alerts and verified cleanup commands.
5. **No Placeholders**: Every curriculum phase, lab, project, and command reference contains complete, verified technical content based on current Google Cloud GA documentation.
